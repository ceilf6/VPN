## 节点与连接方式

| 用途 | 节点或规则 |
| --- | --- |
| 美国候选 | `🇺🇸 美国-洛杉矶 01丨1x US`、`🇺🇸 美国-洛杉矶 02丨1x US` |
| 香港候选 | `🇭🇰 香港 01丨1x HK`、`🇭🇰 香港 02丨1x HK`、`🇭🇰 香港 03丨1x HK` |
| 普通出口 | 选择美国候选组、上述机场节点或DIRECT |
| 住宅出口 | `type: socks5`；`dialer-proxy`保持注释，直接连接住宅服务器 |
| 本地7898入口 | 通过美国候选组使用机场节点 |
| 本地7897入口 | 通过住宅策略组使用住宅SOCKS5 |

住宅节点虽名为`US-Frontier-SSH`，配置类型为SOCKS5。普通机场流量与住宅出口分别连接；此模板不启用“TAG→住宅VPS”的代理链。

## 本地使用

1. 将模板复制为`clash-verge-global.tag.local.js`，填写住宅服务器地址、用户名和密码。此类本地私密副本由`.gitignore`排除。
2. 将企业DNS、企业域名和个人直连规则填写为实际值；不需要的示例规则可移除。示例地址不能作为实际服务地址使用。
3. 核对当前订阅的节点名，再将本地副本内容复制到Clash Verge全局扩展脚本中保存。只应用于与模板节点名称一致的TAG订阅。
4. 查看配置检查结果后验证普通机场出口与住宅出口；导入成功和语法检查均不能替代网络验证。
